# Spec Delta

## ADDED Requirements

### Requirement: Deck preview copy is German

The deck preview SHALL present its page title, heading, and instructional paragraph in German. Face captions SHALL remain the existing German card tokens. The document language SHALL be German.

#### Scenario: Preview chrome is German

- **WHEN** a person opens the deck preview
- **THEN** the heading and the instructional paragraph are in German and the document language is German
