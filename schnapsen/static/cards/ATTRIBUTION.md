# Card drawings

The twenty Schnapsen faces and the card back are from **David Bellot**’s
[SVG-cards](https://github.com/htdebeer/SVG-cards) (also
[svg-cards.sourceforge.net](http://svg-cards.sourceforge.net/) and Wikimedia
Commons `Svg-cards-2.0.svg`).

License: **GNU Lesser General Public License version 2.1 or later** (see
`LICENSE` in this directory).

Each `{token}.svg` file is one group from that pack, with the shared SVG
definitions included so the file can be opened on its own.
